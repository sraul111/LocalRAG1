# `skills/` — guidance for future sessions (human or AI)

These are the lessons, conventions, and traps I wish I'd had *before*
writing the first line of code on this project. They're written in
present-tense ("you", "your") as if addressed to whoever picks up
the work next.

**Read in this order:**

1. **`phase-roadmap.md`** — where the project is, what's left, what not to do.
2. **`coding-style.md`** — module/file/git conventions enforced here.
3. **`testing.md`** — how to add tests the way they were added before.
4. **`resumability.md`** — the crash-safety contract for `sl index` and `sl watch`.
5. **`traps-and-pitfalls.md`** — concrete Rust quirks I had to debug live.

If you only have 5 minutes, read `traps-and-pitfalls.md` and `testing.md`.
